# diary-reel-kit — 지나쌤 My English Diary 제작 프로젝트

이 폴더는 영어일기 쇼츠(9:16)와 유튜브 롱폼(16:9)을 만드는 프로젝트다.
**제작 규칙 전체는 아래 파일에 있다. 일기·릴스·쇼츠·롱폼·표지·voice.mp3 관련 요청이면 먼저 읽고 그대로 따른다.**

@skills/english-diary-pipeline/SKILL.md

- 코드 사용법·팀 구성: `README.md`
- 편별 데이터: `episodes/<이름>/` (config, youtube.json, cover.json, sync.md, caption.md, photos, voice.mp3)
- 시작할 때: `./setup_fonts.sh` (세션마다 폰트·패키지 설치가 필요하다)
- 개발 브랜치에만 push 하고 PR 은 요청이 있을 때만 만든다.
