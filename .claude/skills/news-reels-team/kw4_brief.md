# 키워드 영상 v4 공통 지시 (2026-11-25 회차 대본 v3부터)

## 입력
- 대본·단어 시각: `content/2026-11-25-cnn/audio/words_kw_v3.json['<id>']` (beats: role/speak/show/start/end/first_word_idx/n_words, words: t/s/e), 음성 `audio/v3/kw_<id>.mp3`, 대본 원본 `03_script/kw_scripts_v3.json`.
- roles: hook(1~2줄) → question → answer(정답은… 표현) → meaning → ex1_en → ex1_ko → ex2_en → ex2_ko (→ tail). 저장해 두세요 없음. 마지막 줄이 끝나면 약 0.7초 꼬리 후 끝.
- 화면 글자는 beat의 `show`와 정확히 같다(음성 `speak`과 뜻이 같고, 숫자는 화면에 숫자로). 줄을 마음대로 줄이거나 바꾸지 않는다. 한 줄이 길면 줄바꿈해서 다 보여 준다.
- 싱크는 words의 단어 시각으로만(추정 금지). 단어 길이가 0인 Scribe 값(예: thousand 4.0~4.0)은 최소 0.08초로 보정하고 알린다.

## 구성
- 훅(0프레임부터 문구 전체가 흐리게 보이고 말하는 순간 단어가 채워짐) → 질문 → 정답(표현을 크게, 이 순간이 편당 큰 효과 1개) → 뜻 → 예문 영어(표현 부분 강조)·해석 → 예문2 영어·해석. 
- 표현의 뜻을 보여 주는 핵심 이미지 1개를 화면에 유지한다(그림, 글자 없는 아이콘/일러스트). 새는 `content/assets/bird_sprite.png`, 말할 때 입이 열림(`tools/bird.py`, RMS).
- 영상 크기 1080x1920 30fps h264+aac, 길이 = 음성 + 0.7초.

## 연출 톤: 고급스럽게 (지나쌤 확정)
- 효과는 절제: 번쩍임·화면 흔들림·과한 팝/오버슈트·스크램블·파티클 남발 금지. 느리고 부드러운 이징, 글자는 페이드/슬라이드.
- 팔레트는 채도를 낮추고 2~3색(+ near-black/off-white). 여백을 넉넉히, 글자 위계(표현 > 예문 > 장식).
- 편마다 모션 스타일은 다르게(각 편 지시 참고) 하되 강도는 낮게.

## 레이아웃·검수
- 글자는 x 62~850, y 230~1440 안(오른쪽 230px와 상단·하단 UI 영역 피함). 핸들 `지나쌤영어  @jina.ssam_english` y≈1588. 새가 글자를 가리지 않게.
- 대비는 코드로 계산(큰 글자 3:1, 본문 4.5:1). 순수 검정 대신 near-black.
- 웹 사진·실존 인물 사진 금지. 한글 폰트 Noto Sans CJK.
- 산출물: `content/2026-11-25-cnn/06_keyword_reels/v4/kw_<id>.mp4`(새 폴더 v4; 기존 영상 덮어쓰지 않음). 렌더러는 `.claude/skills/news-reels-team/tools/render_kw4_<id>.py`(NEWS_ROOT 환경변수). 기존 `render_kw_1125_<id>.py`의 새·글자·싱크 코드를 참고해도 되지만 장면 구성은 새로 쓴다.
- 풀해상도 프레임을 비트마다(훅 0프레임, 질문, 정답 시작, 뜻, ex1_en, ex1_ko, ex2_en, ex2_ko, 끝) 직접 열어 확인한다. 줄이 말해지기 전/후 상태, 글자 잘림·겹침 확인.
- 커밋·푸시·파일 전송 금지. 보고: ffprobe, 확인한 프레임, 문제점, 귀로 확인 못 했다는 점(싱크는 단어 시각 기준).
