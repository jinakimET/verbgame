# My English Diary 제작 파이프라인 (확정 규칙)

브랜드: 지나쌤영어 · #지나쌤영어 #realvibejina #영어공부하자. 진짜 일기(자동 생성 X)를 지나쌤 ElevenLabs 클론 음성("Jina", eleven_v4)으로 읽는다.
코드와 데이터는 저장소의 `diary-reel-kit/` 에 있다. **지나쌤이 직접 지시해서 확정한 것은 아래 "확정된 결정"이며 임의로 바꾸지 않는다.**

## 확정된 결정 (지나쌤 지시)
- **캐러셀은 만들지 않는다. 2문장 요약도 만들지 않는다.** (옛 스킬 english-diary-carousel / english-diary-writer 의 요약·한 줄씩 해석 파트는 무시)
- **결과물은 쇼츠(9:16) 릴스 + 유튜브 16:9 롱폼.** 영상 mp4 는 대화창으로 전달한다(용량 때문에 git 제외).
- **팔레트는 자동 확정**한다(후보를 여러 개 보여 주고 고르게 하지 않음). 확정한 팔레트·출처·이유는 한 줄로 알린다.
  - 먼저 `jina-color-chips` 스킬(지나쌤 컬러칩 라이브러리)에서 사진 톤에 맞는 칩을 고른다. **보라 계열로 쏠리지 않게** 다른 색상군을 돌려 쓰고, 쓴 칩은 아래 "사용한 팔레트" 표에 기록한다.
  - 라이브러리에 맞는 칩이 없으면 Color Hunt·Coolors(WebSearch, `allowed_domains` 로 사이트 지정)에서 디자이너들이 많이 쓰는 팔레트를 찾는다. 검색 결과 링크를 출처로 남긴다.
  - 역할 배정: 가장 밝은 색 → BG, 가장 진한 색 → INK, 중간 채도 → MARK(카드·형광펜), 나머지 → LAV/ROSE/SUN. 글자 대비는 코드로 계산(본문 4.5:1, 큰 글자 3:1). 연한 강조색이 없으면 파생 색을 만들고 그렇다고 밝힌다.
  - `#000` 대신 near-black. ≈ 표시가 붙은 칩 색은 처음 쓸 때 한 줄로 확인한다.
- **캡션**: 짧은 도입(일기 한 줄 감성) → 오늘의 표현 목록(이모지 영/한) → `오늘 일기, 두 줄만 따라 써 보세요 ✍️` → 해시태그 5개.
- **표지**: 첫 번째 사진 = 표지. 한글 키워드 + 영어 빈칸 문장. 금지 문구: "이거 보고 가세요", "~ 모르면", "영어로 하면". 사진 수가 부족하면 표지 사진을 다른 장면에 재사용한다.
- **롱폼 길이는 약 1분 10초**, BGM 없음(원본 음성 + 쇼츠의 '뿅' 효과음만), 마지막에 "노트에 직접 써 보면 훨씬 도움돼요 ✍️" 안내를 한 번.
- **데이터 직접 사용**: 롱폼은 완성된 영상에서 뽑지 않고 timing·사진·팔레트·표현 데이터를 직접 읽는다.

## 팀 (7 역할)
1 PD(재료 점검·중복 확인) · 2 영어 에디터 · 3 컬러 디렉터 · 4 음성·싱크 · 5 릴스 렌더 · 6 QA·카피 · 7 롱폼 제작. 한 사람이 여러 역할을 겹쳐 해도 되지만 각 단계의 산출물과 검수는 빠뜨리지 않는다.

## 흐름과 규칙
**0. 시작(세션마다)**: `cd diary-reel-kit && ./setup_fonts.sh` (폰트·패키지 설치). 이 환경엔 Noto CJK Medium/Black 이 없어 Regular/Bold 로 대체한다.

**1. 일기 검토(에디터)** — 지나쌤이 메모(한글/영어 초안)를 보내면:
- 원문 체크: `원문 → 교정` + 이유 한 줄. 의미가 모호하면 어떻게 이해했는지 밝힌다. 원문에 없는 내용을 덧붙였으면 표시한다.
- 최종 일기: 영어 4~6문장, 일상 구어 톤, 핵심 표현 **굵게**, 한글 해석. 성별이 불분명한 사람은 가정하지 않는다(my spouse 등). 이미 승인된 문장은 임의로 바꾸지 않는다.
- ElevenLabs 대본(코드블록, 문장당 한 줄, 태그·괄호 없음), 표현카드 7개(이모지·영/한, ZWJ 이모지·⏳ 금지), 표지 키워드 제안, 사진 배치 제안.
- 표현은 7개로 맞춘다(롱폼 복습이 2개씩 + 마지막 노트 안내 구조). 음성은 지나쌤이 직접 만든다(크레딧) — 새로 생성하지 않는다.

**2. 사진 → 팔레트 → 표지(컬러 디렉터)**: 첫 사진이 표지. 표지는 음성 없이 먼저 렌더해 보여 준다.
`episodes/<이름>/cover.json` 작성 후 `python3 covers.py episodes/<이름>/cover.json`. 인물이 글자와 겹치면 `zoom`/`fx`/`fy` 로 조정, 키워드가 길면 `ksize` 를 줄인다(폭 초과 경고가 뜬다). 얼굴이 글자에 가려지지 않는지 눈으로 확인.

**3. 음성 도착 → 싱크(음성·싱크)**: `ffmpeg silencedetect`(-35dB/0.25s 문장, -30dB/0.08s 쉼표) + 음절 수 비례로 문장·구절 경계를 대조한다. 전사 도구가 없으면 음절 수로 맞는지 검산한다. 결과를 `episodes/<이름>/sync.md` 에 남긴다. 음성은 귀로 들을 수 없으므로 반드시 그렇게 밝히고 마지막 단어가 잘렸는지 들어 봐 달라고 한다.

**4. 쇼츠 렌더(릴스)**: `python3 use_episode.py <이름>` → `timing.py`(문장·chunks·display·cards)·`episode_cfg.py`(PHOTOS·DUR·END_T0·LOOP_T0)·`palette.py`·`exprs.py` 작성 후 `python3 make_audio.py` → `python3 render3.py sheet "…"`(컨택트 시트 확인) → `python3 render3.py video`. 끝나면 `python3 use_episode.py <이름> --save`.
- 1080x1920, 30fps. 손글씨 "My English Diary" + 태그라인 + 진행 점, 사진 1080x600, 영어 문장(단어 하이라이터) + 한글 해석 박스, 표현 카드 뿅 → 카운터로 날아감, 엔딩 "오늘 써볼 표현", 끝 0.75초 첫 프레임 블렌드(루프).
- **첫 카드는 첫 문장(0~1초대)부터**, 카드 간격 최소 1.4초, 카드 문구는 짧게. 에피소드 번호는 영상에 넣지 않는다. 음성 속도 변경(0.9x 등) 금지. -14 LUFS.
- DUR = 마지막 발화끝 + 0.25 + 0.23 + 5.55, END_T0 = 엔딩 시작, LOOP_T0 = DUR - 0.75.
- 검수: 하이라이트가 발화와 맞는지, 텍스트가 박스 밖으로 안 넘치는지, 엔딩 목록 = 실제 카드, 표지 글자 잘림 없음.

**5. 유튜브 롱폼(롱폼 제작)**: `episodes/<이름>/youtube.json`(화면 분할·한글 분할·말풍선·노트 문구·썸네일·제목·챕터·timing) 작성 후 `python3 youtube16.py episodes/<이름> all`.
- 1920x1080 30fps. 문장 화면(≤2줄, clause 경계에서 분할) → 해당 표현의 카드(2.8~3.0초, 표현이 둘이면 카드도 둘) → 복습(표현 2개씩 2블록, 한쪽씩 번갈아 강조, 마지막에 노트 안내 블록). 화면마다 말풍선 2개(첫 줄 단어는 위, 마지막 줄 단어는 아래, 표현 단어와 겹치지 않게).
- 오디오는 원본 voice.mp3 조각(앞 15ms 페이드 인, 끝 40ms 페이드 아웃)을 쉼 안쪽에서 자르고, 컷 지점 에너지를 수치로 확인한다. 카드·복습 구간은 무음 + '뿅'(+0.1초). 최고 음량 -1 dBFS 이하.
- 썸네일 2종(1280x720): A 주제, B 질문형. 제목 후보 3개, 설명란(도입·챕터·표현·영어/해석 번갈아 배열 원문·해시태그). **챕터는 3개 이상, 각 10초 이상.**
- 파일명: `지나쌤_영어일기_<주제>_유튜브용.mp4` (수정본은 _v2).

**6. 전달·보고(QA)**: SendUserFile 로 영상·표지·썸네일·메타·캡션 전달. 마지막 답은 짧게: 길이·구성, 확인이 필요한 임의 선택(말풍선 단어·뜻, 한글 분할, 썸네일/제목 문구), **"귀로 듣지 못함" 안내**, 파일명. 저장소에는 설정·코드·사진·음성·표지·메타를 커밋하고 개발 브랜치에만 push 한다(PR 은 요청 시에만).

## 지나쌤이 이렇게 말하면 이렇게 진행
| 지나쌤 말 | 하는 일 |
|---|---|
| "새 일기 시작" + 메모 | 1단계: 원문 체크·일기·대본·표현카드·표지 키워드 |
| 사진 첨부(첫 장=표지) | 2단계: 팔레트 자동 확정 + 표지 렌더 → 표지 전달 |
| voice.mp3 첨부 | 3~6단계: 싱크 → 쇼츠 → 롱폼 → 전달 |
| "표지 문구 ~로 수정, 사진·컬러 그대로" | `cover.json` 만 고쳐 표지만 다시 렌더 |
| "문장 ~로 수정" | 승인된 부분은 두고 그 부분만 수정, 바뀐 곳 굵게 |
| "롱폼만 다시" | `youtube16.py episodes/<이름> all` 재실행 |

## 알려진 제약·확인 필요
- 쇼츠 `render*.py` 는 import 시점에 `voice_pad.wav` 를 읽으므로 `make_audio.py` 이후에만 실행된다.
- 롱폼 "BGM 필요없어 쇼츠 영상 그대로"는 **BGM 없음**으로 해석했다(2편). BGM 을 원하면 쇼츠의 `bgm.wav` 를 재사용한다.
- 인스타 핸들이 스킬마다 다르다(`jina.ssam_english` vs `@realvibejina`). 확정 전까지 설명란에 넣지 않는다.
- 렌더 코드는 이 환경에서 1·2편으로만 검증했다. 새 문제가 나오면 고치고 이 문서에 반영한다.
