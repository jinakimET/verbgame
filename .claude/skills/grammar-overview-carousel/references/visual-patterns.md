# 텍스트 시각화 패턴 사전 (정지 카드용)

한 장에 주인공 패턴 1개. 이름만 말하면 아래 스펙으로 바로 넣는다.
(영상용 모션 효과는 노션 '영상 효과 & 디자인 포맷 사전' 참고. 캐러셀은 정지 이미지이므로 '멈춘 순간'으로 표현한다.)

## 인라인 표시 (문장 안에서) — 모든 문자열에서 사용 가능

| 쓰기 | 모양 | 언제 |
|---|---|---|
| `==to study==` | 형광펜(PK) | 이 장의 핵심 덩어리 |
| `++to see++` | 보조 형광펜(LP) | 둘째 강조, 비교 대상 |
| `@@to be@@` | 셋째 강조(ACC) | A vs B의 B쪽 |
| `[[to read]]` | 덩어리 괄호 칩(점선 테두리) | "여기까지가 한 덩어리" |
| `~~it~~` | 회색 취소선 | 틀린 부분, 빼 보기 |
| `__glad__` | 굵은 밑줄 | 짝꿍 단어(형용사·동사) |
| `{{목적}}` | 작은 진한 알약 | 문장 안에 붙이는 라벨 |
| `<br>` | 줄바꿈 | |

## 블록 패턴 (`blocks` 배열 안)

| 이름 | type | 언제 |
|---|---|---|
| 예문 줄 | `rows` | 영어 + 오른쪽 해석. 2~4줄 |
| 포인트 | `point` | 테두리 박스, 큰 글씨 한두 줄 규칙 |
| 알고 보면 / 팁 | `dark` | 어두운 박스, 자세한 설명 |
| 빼 보기 테스트 | `strip` | 문장에서 덩어리를 빼 보고 완전/불완전 판정 → 종합편 연결 고리에 최적 |
| 대결 | `vs` | 두 칸 비교 (A vs B), 각 칸 제목·예문·한 줄 |
| 함정 | `trap` | ✖ 문장 → ⭕ 문장 + 이유. 2~3개 |
| 한 장 지도 | `map` | 벤토 그리드. 가운데(위) 허브 + 갈래 카드 4~6개 |
| 흐름 | `flow` | 칩 → 칩 → 칩 (판정 순서, 해석 순서) |
| 짝꿍 구름 | `cloud` | 같이 다니는 단어 칩 모음 (glad · sorry · surprised …) |
| 문장 변주 | `morph` | 고정 앞부분 + 바뀌는 뒷부분 여러 줄 (C 한 문장 변주형) |
| 퀴즈 | `quiz` | 문제 목록 + 정답 박스 |
| 미리 보기 | `next` | 점선 박스, 다음 편 예고 |

## 장 종류 (`kind`)
- `cover` 표지 · `concept` 기본 개념 카드 · `summary` 어두운 정리 카드 · `quiz` 퀴즈 카드
- 모든 장 상단에 `mapNav`(지도 위치 칩 줄)를 켤 수 있다: `"nav": 2` (지도 갈래 번호, 1부터)

## 고르는 기준
- 개념이 여러 갈래 → `map` 한 장 + 이후 장 `nav`
- 비슷한 것끼리 헷갈림 → `vs`, `strip`
- 시험 함정 → `trap`
- 의미가 뒤에 붙는 말에 따라 바뀜 → `morph`
- 외워야 할 짝꿍 단어 → `cloud`
