# 어법 종합편 캐러셀 · 총괄 워크플로

목표: 사람들이 **여기저기 흩어져서 따로따로 알고 있는 어법 내용을 한 군데에 연결해서 한 번에** 보여 주는 캐러셀.
한 장에는 예문 2~4개 + 눈에 확 들어오는 텍스트 시각화 1개(형광펜·덩어리 괄호·✖→⭕·지도 등).
답은 한국어로, 짧게. 브랜드는 `references/brand.md`를 따른다.

## 사용하는 파일

| 파일 | 내용 |
|---|---|
| `references/brand.md` | 지나쌤영어 시그니처(고정 규칙, 말투, 핸들, 금지 문구) |
| `references/palettes.md` | 저장 팔레트 목록 + 사용 기록 + 역할 배정 규칙 |
| `references/visual-patterns.md` | 텍스트 시각화 패턴 사전 (이름 → 언제 쓰는지 → 스펙 문법) |
| `references/rubric.md` | 시안 평가 기준(100점) |
| `references/spec-format.md` | 시안 JSON 형식 (렌더러 입력) |
| `render/render.js` | JSON → PNG + 한눈에 보기 시트 + 넘침 검사 |
| `examples/to-inf-adverbial.json` | 완성 예시 (to부정사 부사적 용법, 지도형) |

## 단계

### 1. 주제 확인 (질문 최소화)
- 주제를 한 줄로 되묻지 말고 바로 진행한다. 다만 아래가 애매할 때만 AskUserQuestion으로 한 번에 묻는다(최대 4개, 추천안 첫 번째 + "(추천)").
  - 대상: 중학생 / 고등 내신 / 수능 / 성인 회화
  - 시리즈 번호를 붙일지(기존 `hs-grammar-carousel` 시리즈와 연결되는 주제면 해당 편 번호 언급. 예: to부정사 → 004, 004-3 해석 5종)
- 지나쌤이 준 예문·문구는 그대로 쓴다. 바꾸고 싶으면 이유와 함께 제안만.

### 2. 혼동 지도 만들기 (직접)
스크래치패드에 `confusion-map.md`를 쓴다.
- 이 주제에서 학습자가 **헷갈려하는 지점 5~8개**: 비슷해 보이는 다른 문법(예: 부사적 vs 명사적 vs 형용사적), 해석이 갈리는 지점, 시험 함정(내신 어법·수능 29번·TOEIC Part 5 유형).
- 필요하면 WebSearch(standard)로 출제 유형을 확인하고, 확인 못 했으면 "전형 유형으로 골랐다"고 솔직히 적는다.
- 흩어진 지식을 **하나로 묶어 줄 연결 고리 1개**를 정한다 (예: "to 덩어리를 빼 봐도 문장이 완전하면 부사적"). 이게 종합편의 심장이다.

### 3. 시안 3개 (직접 작성)
아래 세 각도로 시안 JSON을 하나씩 직접 쓴다(spec-format.md·visual-patterns.md·brand.md 기준, 각자 렌더해서 넘침 0까지):
- **A 지도형** — 2장에 한 장 지도(벤토 그리드)로 전체를 먼저 보여 주고 → 갈래별 확대 → 헷갈림 해결 → 정리.
- **B 헷갈림 해결형** — "이거 뭐야?" 비교쌍으로 시작. 매 장이 ✖/⭕ 또는 A vs B 대결.
- **C 한 문장 변주형** — 기본 문장 하나를 계속 바꿔 가며(뒤에 붙는 to 덩어리만 교체) 뜻이 바뀌는 걸 보여 줌.
출력: `<scratch>/drafts/A.json`, `B.json`, `C.json`.
지나쌤이 "시안 2개만" 등 수를 말하면 그만큼만.

### 4. 평가·추천
rubric.md 기준으로 세 시안을 직접 채점하고(예문 문법 검사 포함) 점수표 + 추천 + 섞을 점(예: "A 구성에 B의 7장 함정 카드")을 정리한다.
그 사이 세 시안을 각각 렌더해서(`node render.js drafts/A.json out/A` …) 한눈에 보기 시트 3장을 만든다. 팔레트는 아직 미정이면 `palettes.md`의 '시안용 중립' 팔레트로.
지나쌤에게: 시트 3장 SendUserFile + 점수표(5줄 이내) + 추천 1개 → AskUserQuestion으로 고르게 한다(추천 첫 번째, "섞기" 옵션 포함).

### 5. 디자인 결정
1. **레퍼런스 사이트**: 지나쌤이 URL을 주면 직접 보고(Playwright 스크린샷 또는 WebFetch) 디자인 토큰(레이아웃·타이포 크기 비율·여백·모서리·그림자·강조 방식)을 뽑는다. 사이트를 못 받았으면 묻는다(건너뛰기 가능 → 기존 네오 브루탈리즘 시그니처 유지).
   - 레퍼런스는 **분위기와 구조만 빌린다**. 로고·일러스트·고유 문구를 복제하지 않는다. 지나쌤 시그니처(brand.md의 '절대 유지') 위에 얹는다.
2. **팔레트**: `palettes.md`에서 고른다.
   - 지나쌤이 Color Hunt 링크를 주면 URL 끝 hex 4개(6자리씩)를 쓰고 `palettes.md` 저장 목록에 추가.
   - 안 주면 저장 목록 중 **최근 사용 기록과 겹치지 않는 것** 2개를 추천해 고르게 한다.
   - 역할 배정은 렌더러가 자동(`"palette": ["#hex",…]`)으로 하되, 결과가 어색하면 `DK/BG/PK/LP/SUB/ACC`를 직접 지정.
3. 표지 사진: 시리즈 규칙상 동물 사진을 쓰는 편이면 요청. 없으면 사진 없는 타이포 표지로.

### 6. 제작
1. 고른 시안 JSON에 팔레트·스타일·피드백을 반영해 `final.json`.
2. `node render.js final.json <out>` → `slide_01.png …` + `sheet.png` + 넘침 보고.
3. **검수(필수)**: sheet.png와 넘침 경고가 난 장은 개별 PNG를 Read로 직접 본다. 확인할 것:
   - 넘침 경고 0개, 글자 깨짐(□) 없음, 하이라이트가 위아래 줄 글자를 가리지 않음
   - 형광펜 색 = 연결되는 정리 박스 색
   - 예문 영어가 자연스러운지, 해석이 맞는지 한 번 더
4. SendUserFile로 sheet + 전체 PNG 전달, 장별 한 줄 요약. 수정 요청은 해당 장만 고쳐 같은 이름으로 다시.

### 7. 마무리
- `palettes.md` 사용 기록에 (날짜, 주제, 팔레트) 한 줄 추가.
- 노션 기록은 지나쌤이 원할 때만 (제작 현황 표 `collection://09e42e75-1c47-4aef-8c26-b76e29b2b094`, 핸드북 `3ffc815c5bac81e5a10ad6ad749f3f4a`).
- 캡션이 필요하면 도입 한 줄 → 핵심 정리 3줄 → 저장 유도 → 해시태그(#지나쌤영어 #realvibejina #영어문법).

## 렌더러 실행
```bash
cd .claude/skills/grammar-overview-carousel/render
node render.js ../examples/to-inf-adverbial.json /tmp/out   # 출력: slide_NN.png, sheet.png
```
Playwright는 이미 설치돼 있다(재설치 금지). 폰트는 Google Fonts(Black Han Sans, Noto Sans KR)에서 불러온다.
